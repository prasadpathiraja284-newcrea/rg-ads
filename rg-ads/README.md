# RG Ads

Single-page site for RG Ads. Open `index.html` in a browser (double-click it), or serve the folder:

```powershell
cd C:\Users\New\rg-ads
python -m http.server 8080
```

Then visit http://localhost:8080

To add AI videos, drop `.mp4` files into `videos/` using the names in that folder’s README, or change the `src` paths in `index.html`.
